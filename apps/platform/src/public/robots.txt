# `Disallow: /dashboard` already covers every path beneath it — a robots.txt
# rule is a prefix match, not an exact one — so the per-page /dashboard/builder
# and /dashboard/deploy lines were redundant. /auth was missing entirely: those
# are OAuth callback URLs carrying one-time codes and there is no reason for a
# crawler to fetch them.
#
# The named Googlebot/GPTBot groups exist to state intent explicitly, not to
# change behaviour: a crawler obeys only the most specific group that matches
# it, so each one has to repeat the whole ruleset rather than inherit from `*`.
